# Chinese Sentence Proofreader

面向中文论文 Word 文档的病句专项审校 Skill。聚焦句式杂糅、成分残缺、指向不明、搭配不当，以及长句中的施事、并列和比较关系；不把一般润色偏好当作语法错误。

## 输出方式

默认生成独立、可编辑的 DOCX 副本，并保留原有 Word 批注。含义可确定的病句直接修改，新增原生批注说明原文、修改及句法理由。需要作者决定原意的原文保留并标红；依赖事实或出处查证的原文保留并标橙；已直接修改的文字标蓝。

| 颜色 | 状态 |
| --- | --- |
| 蓝色 | 已修改 |
| 红色 | 需作者修改 |
| 橙色 | 待核实 |

每条批注仍写具体语病类别和处理建议。纯删除用删除点紧邻的最短保留文字作蓝色定位标记，并在批注中留存被删原文。明确要求仅批注或 Word 修订记录时，按请求处理。

## 判定原则

- 阅读完整句子及相邻上下文，先找各分句的主语、谓语和必需成分，再核对并列项与共用谓语、比较双方、指代和关联词。
- 只有能解释具体句法冲突或搭配不成立的候选才进入批注；合理省略、无主句、专业术语及个人行文习惯不机械判错。
- 改法唯一时做最小必要修改；作者意图不明时指出需作者确定的主体、对象或关系，不臆造论文内容。
- 逐项核对正文变化、处理状态颜色、批注锚点、原有内容及页面渲染；结构检查与 Word 界面检查分别报告。

本 Skill 当前为 **Draft / Unvalidated**：规则已可用于人工审校流程，但尚无经独立标注的语法准确率或召回率评测结果。

## 安装

```bash
git clone https://github.com/Essarai/chinese-sentence-proofreader.git \
  ~/.codex/skills/chinese-sentence-proofreader
```

示例请求：

> 使用 chinese-sentence-proofreader 细审这篇论文的病句。确定的语法错误直接在 Word 中修改并标蓝；需作者定稿的标红，待核实的标橙，每处保留具体说明批注。

运行时需要可编辑、可写入原生批注并可渲染的 DOCX 工具。本仓库提供审校规则，不附带文档编辑工具，也不默认开展史实和参考文献全量核验。
